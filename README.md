# 💯 100 Basic Questions — Roadmap

100 beginner-friendly programs to build your **problem-solving skills** before you touch LeetCode or DSA.

The questions are arranged from easy to hard: basics first, then moderate, then a challenge round. Pick one language (**Python / Java / C++**) and solve all 100 in it.

> 📌 Wherever you see `n`, it is taken as **user input**.

## 🚀 How to Use This Repo

### Step 1: Clone the repo

```bash
git clone https://github.com/iamaniket-python/100-basic-questions--Roadmap.git
```

### Step 2: Move into the folder

```bash
cd 100-basic-questions--Roadmap
```

### Step 3: Switch to the branch

```bash
git checkout level1
```

### Step 4: Open a level folder

Open the folder of the level you want to practice and solve the questions in order.

### Step 5: Solve it yourself first, then compare

Try each question on your own before looking at any solution. That struggle is where the real learning happens. 💪

---

## 📏 Rules to Follow

1. **Pick one language** and use it for all 100 programs. Don't keep switching.
2. **Solve strictly in order.** The problems are arranged from easiest to hardest for a reason.
3. **Do not look up the solution first.** Struggle for 10–15 minutes on your own. That is where problem-solving is actually built.
4. **Type the code yourself** every single time. No copy-paste.
5. After each program works, ask: *"Can I do it with fewer lines or cleaner logic?"*
6. Wherever `n` appears, **read it from the user** as input.
7. Tick off each problem as you finish it. Aim for **3–5 programs per day** and you'll be done in about a month.

> **Rule of thumb:** Finish these 100 first. Then go anywhere: DSA, LeetCode, or projects.
